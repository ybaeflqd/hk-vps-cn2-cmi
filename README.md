## 三网优化到底在优化什么

大陆访问香港，数据包默认走中国电信 163 骨干网（AS4134）。这条通道承载了全国大部分民用流量，晚高峰被视频、下载、游戏占满，延迟从白天的三四十毫秒涨到 100ms 以上，丢包率能到两位数。

“优化”就是让数据包绕开这段拥堵，或者至少绕开一部分。三家运营商各有自己的优质通道：电信看 CN2（AS4809），联通看 AS9929 或 AS10099，移动看 CMI（AS58453，走香港到广州陆缆入境）。三条都接上，才配叫三网优化；只接一两条、剩下走普通 BGP 的，晚高峰照样拉胯。

CN2 内部还分等级。GIA 的特征在路由追踪里很直观：能看到连续的 `59.43.x.x` 节点，从用户本地一直持续到香港机房，晚高峰有最高 QoS 优先级。GT 只在国际出口才切进 59.43，国内段仍然走 163 的 `202.97` 节点，最容易堵的那一段没避开。市面上标“CN2”却不写 GIA 的机器，默认是 GT，甚至只有去程走 CN2、回程落回 163 的半程方案。

## 常见问题

**CN2 双向和 CN2 GIA 哪个更值？**

GIA 是 CN2 里的最高等级，全程走专网，晚高峰最稳，代价是带宽窄、价格高。CN2 双向指去程回程都走 CN2 但不一定是 GIA 级别，性价比更高。对绝大多数建站和 API 业务，两者体感差距不大；只有对晚高峰稳定性有硬性要求的场景（远程办公、实时通信、电商后台），GIA 的溢价才值。

**10Mbps 带宽会不会太小？**

看跑什么。纯文字博客、API 接口、小程序后端，10Mbps 完全够用。图片站、视频站、文件下载建议 20Mbps 起步。带宽和流量是两回事，10Mbps 配 1TB 月流量，意味着你可以慢慢传很多数据，但同一时刻的传输速度有上限。

**晚高峰怎么测才算数？**

晚上八点到十一点，用你自己的宽带 mtr 测试 IP，跑够 100 个包看丢包率。白天测出来的 30ms 不代表晚高峰也是 30ms，很多线路白天和晚上的差距能到三倍。

**原生 IP 和广播 IP 有什么区别？**

原生 IP 是当地真实分配的 IP 段，归属地就是机房所在地；广播 IP 是商家从别处广播过来的，归属地可能显示为其他地方。对 TikTok、ChatGPT、流媒体这类会查 IP 归属的平台，原生 IP 通过率更高。

**年付一定比月付划算吗？**

算总账。年付单价低，但一次性付清，中途换方案不好退。不确定能不能用满一年，先月付跑一两周，确认线路稳定再转年付。
